# 从0制作具身机器人

## 项目简介
从零开始设计和制造一个具身机器人（Embodied Robot），涵盖结构设计、电路设计、程序控制和人工智能。

## 目录结构
```
robot/
├── docs/           # 设计文档和讨论记录
│   ├── PLAN.md     # 总体规划
│   ├── mechanical/ # 机械结构设计文档
│   ├── electrical/ # 电路控制设计文档
│   └── software/   # 软件与AI设计文档
├── cad/            # CAD模型和3D打印文件
├── pcb/            # PCB设计文件
├── firmware/       # 嵌入式固件代码
├── software/       # 上层软件和AI代码
├── materials/      # 物料清单 (BOM)
└── README.md       # 本文件
```

## 目标
- 从零开始设计、制造一个可运行的具身机器人
- 在实践中学习机器人学、嵌入式系统、AI/RL
- 开源分享全过程
