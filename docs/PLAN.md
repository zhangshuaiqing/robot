# 从零到产品原型：轮式/履带机器人总体规划

> 长期愿景：多模态智能体机器人（感知→决策→执行全链路）  
> 中期目标：人形机器人  
> 近期目标：轮式/履带机器人产品原型（打好底盘、感知、控制、AI的基础）

---

## 一、核心理念

**软件定义机器人。** 采用"通用硬件平台 + 可升级软件栈"架构：硬件做到够用、可靠、可复现；软件采用分层设计，上层AI/控制逻辑与底层驱动分离。

### 路线图

```
轮式/履带平台 ──→ 人形机器人 ──→ 多模态智能体
    ↓                  ↓                ↓
  运动控制基础      关节控制        多感官融合
  SLAM/导航        双足平衡        (视觉/触觉/听觉/
  感知+AI基础     上层AI迁移      语音/力觉/嗅觉)
                                  统一认知架构
                                  多形态协作
```

**轮式是第一步，不是最终形态。** 每一阶段的软件和算法（导航、感知、AI决策）都可以向上复用。

### 为什么先做轮式

### 什么是"多模态智能体机器人"？

多模态机器人是指能够**融合多种感官输入**来感知环境、做出决策、并与物理世界交互的机器人系统。

```
                    ┌── 视觉（Camera / LIDAR / 深度相机）
                    ├── 听觉（麦克风阵列 / 声源定位）
多模态感知 ──────── ├── 触觉（触觉传感器 / 力传感器 / 柔性皮肤）
                    ├── 力觉（关节力矩 / 六维力传感器 / 末端力控）
                    ├── 听觉语言（ASR / 自然语言理解）
                    └── 其他（温度 / 湿度 / 气体 / 嗅觉等）

                    ┌── 运动（轮式 / 履带 / 双足 / 四足 / 蛇形）
多形态执行 ──────── ├── 操作（夹爪 / 灵巧手 / 机械臂）
                    ├── 交互（表情 / 手势 / 语音合成）
                    └── 协作（多机器人协同 / 人机协作）

                    ┌── 多模态感知融合（视觉+触觉+力觉...）
统一认知架构 ────── ├── 大模型驱动的任务规划与推理
                    ├── 统一的环境表征（语义地图 + 物体模型）
                    └── 自主学习与适应
```

**我们的路线**从最简单的轮式运动和视觉开始，逐步叠加触觉、力觉、听觉、语言等模态，最终构建一个能够像人一样融合多种感官理解世界、并在不同形态（轮式→人形）上运行的智能体。

| 维度 | 轮式/履带 | 人形双足 |
|------|-----------|----------|
| 运动学复杂度 | 简单（2-4自由度） | 复杂（20+自由度） |
| 控制频率要求 | 50-200Hz | 500-1000Hz |
| 机械制造难度 | 铝板/亚克力切割即可 | 需要CNC/3D打印/精密加工 |
| 软件可迁移性 | SLAM导航\感知\AI全可迁移 | — |
| 从0到跑通时间 | 1-2个月 | 半年+ |

**结论：轮式平台是通往人形最有效的中间步骤。** 建图、导航、避障、感知、大模型对接等核心AI能力全可以在轮式上先跑通。

## 二、产品定位（建议讨论）

在设计之前，先想清楚做什么产品。几个可能的定位：

1. **智能巡检/安防机器人** — 室内巡逻，SLAM自主导航，异常检测
2. **配送/跟随机器人** — 仓库/园区物料运输，行人跟随
3. **通用开发平台** — 开源ROS2平台，可二次开发
4. **家政服务机器人** — 扫地+搬运+语音交互

> 推荐起步定位：**智能巡检开发平台** — 技术覆盖面广（SLAM/导航/避障/检测），后期很容易转为配送或家政，且与你的RL+AI研究方向高度相关。

### 推荐硬件方案（最终决策：2026.5.23讨论确定）

| 层级 | 推荐选型 | 备选 | 说明 |
|------|---------|------|------|
| 核心计算 | **NVIDIA Jetson Orin Nano** (8GB) | 树莓派5 / Intel NUC | 兼顾算力、功耗、生态，方便跑视觉AI |
| 底层控制器 | **ESP32-DevKitC V4** | STM32F4/F7 | Arduino框架入门，零固件经验友好，成本~25元 |
| 驱动电机 | **JGA25-371 直流有刷编码电机** | 无刷MG310+AS5600 | 有刷+编码器方案成本低、控制简单，适合入门。无刷为进阶方向 |
| 电机驱动 | **TB6612FNG 双路驱动模块** | L298N（不推荐） | TB6612效率高、发热小，2A持续够用 |
| 底盘 | **4轮差速两驱**（后轮驱动+前万向轮） | 履带式（更贵、里程计漂移） | 成本低、SLAM建图精度高、结构简单 |
| 激光雷达 | **RPLIDAR A1/A2** (2D SLAM) | YDLIDAR X4 | 性价比高，室内建图够用 |
| 深度相机 | **Intel Realsense D435** | OAK-D | SLAM+避障+物体检测一条龙 |
| IMU | **MPU6050 (GY-521)** | ICM-20948 | 6轴够用、资料最多、成本仅8元，对初学者极友好 |
| 电池 | **3S LiPo 2200mAh + 降压模块** | 4S 5000mAh | 3S 11.1V够电机用，成本更低 |
| 结构 | **成品4WD铝合金底盘** | 自制铝板切割 | 买成品省去底盘加工时间，集中在电控和软件 |

## 五、关键技术选型详解

### 5.1 电机方案：直流有刷+编码器 vs 无刷

```
学习阶段推荐:        最终产品可选:
JGA25-371有刷+编码器   MG310无刷+ODrive
├─ 成本: ~30元/对      ├─ 成本: ~200元/对
├─ 控制: 简单的PWM+DIR   ├─ 控制: 需要FOC调参
├─ 编码器: 标配AB相      ├─ 编码器: AS5600磁编码
├─ 入门难度: ★★          ├─ 入门难度: ★★★★
└─ 适合: 快速出成果       └─ 适合: 高性能需求
```

**推荐：JGA25-371 直流有刷减速电机（带AB相编码器）+ TB6612FNG 驱动**

理由：
- **你零固件经验**，有刷电机控制逻辑极其简单（PWM调速+DIR换向），1小时内就能转起来
- 自带AB相编码器，可做PID闭环速度控制
- TB6612FNG比L298N效率高得多（MOSFET低导通电阻），发热小不烫手
- 两款都是成熟产品，教程极多
- **等底盘跑通了，再换成无刷方案升级性能**

### 5.2 控制架构：为什么分两层？

很多初学者用一个树莓派搞定所有，但会有问题：
- Linux是非实时系统，电机PID控制周期不固定会导致抖动
- 高负载（SLAM+视觉）时电机响应滞后 → 翻车/撞墙

**分两层：**
- **底层（ESP32）**：RTOS或裸机循环，负责电机PID控制在10ms内响应，同时处理编码器、IMU、限位开关、电压监测等
- **上层（Jetson）**：Linux+ROS2，负责SLAM、导航、视觉、AI推理

两者通过**USB串口（UART）**通信，协议自定义但稳定可靠。

### 5.3 软件栈

| 功能 | 方案 | 备注 |
|------|------|------|
| 底层固件 | ESP-IDF / Arduino-ESP32 | 建议ESP-IDF，更稳定 |
| 中间件 | ROS2 Humble (Jazzy) | 机器人事实标准 |
| 建图 | Cartographer | Google开源，效果好 |
| 导航 | Nav2 | ROS2官方导航栈 |
| 视觉 | YOLOv8 / RT-DETR | 检测+分割一条龙 |
| 大模型 | LangChain + 本地/云端LLM | 你的老本行 |
| 远程监控 | WebRTC + FastAPI | 低延迟视频流 |

## 六、后续方向：人形→多模态机器人

### 6.1 从轮式到人形

做轮式过程中可以同时积累人形所需的知识：

1. **认识电机种类与应用场景**（BLDC、伺服、步进、关节电机、空心杯）
2. **IMU/里程计融合** → 人形的姿态估计（VIO/FGO）
3. **ROS2基础** → 人形同样跑ROS2，架构不变
4. **视觉感知** → 人形更依赖深度相机+视觉语言模型（VLM）
5. **路径规划/避障算法** → 可复用
6. **大模型Agent架构** → 高层任务规划完全复用
7. **PID/MPC控制基础** → 为多自由度控制打基础

### 6.2 从人形到多模态智能体

人形之后，多模态扩展的主要方向：

| 模态 | 硬件 | 软件 | 阶段 |
|------|------|------|------|
| **触觉** | 电阻式触觉阵列 / 电容式柔性皮肤 | 触觉信号处理、接触状态估计 | Phase 6 |
| **力觉** | 六维力传感器（末端） / 关节力矩传感器 | 力控阻抗/导纳控制、柔顺操作 | Phase 6 |
| **听觉** | ReSpeaker 麦克风阵列 / XMOS | 声源定位、语音增强、ASR | Phase 5 |
| **声音交互** | 扬声器 | 语音合成、情感化TTS、对话管理 | Phase 5 |
| **多机器人** | 多台设备 + 通信模块 | 分布式SLAM、多机协作规划 | Phase 7 |
| **统一认知架构** | — | 多模态融合Transformer、世界模型、记忆系统 | Phase 8 |

### 6.3 长期愿景：统一认知架构

```
输入模态 ──┐
视觉       │
触觉       ├──→ 多模态编码器 ──→ 场景理解 ──→ 任务规划 ──→ 运动/操作
力觉       │         ↑              ↑              ↑
听觉 ──────┘         │              │              │
语言 ───────────────→ LLM/VLM ───→ 记忆系统 ───→ 安全约束
```

最终目标：一个**统一认知架构**，让不同形态的机器人（轮式/人形/机械臂）共享同一套感知-推理-执行闭环。
