# 底层技术选型综合报告

> 适用范围：4轮差速通用开发平台
> 口味：实用优先，快速出成果
> 用户背景：有Python/Linux/硬件焊接经验，**零固件经验**

---

## 一、核心推荐（一句话版）

| 项目 | 推荐 | 理由 |
|------|------|------|
| 仿真环境 | **Ubuntu 22.04 + ROS2 Humble + Gazebo Classic** | 最稳组合，教程最多，RTX 3060兼容 |
| 主控制器 | **Jetson Orin Nano（上层）+ ESP32 via Arduino（底层）** | 仿真先跑通，后期再加实物层 |
| 学习路径 | **先学Arduino C++ → 跑通ESP32 → 再考虑ESP-IDF/STM32** | 从零开始效率最高 |
| 电机方案 | **直流有刷编码电机 + TB6612FNG驱动** | 最实用、最便宜、最易调通 |
| 控制架构 | **ros2_control + 硬件抽象层** | 仿真→实物代码复用 |
| micro-ROS | **不需要** | 增加复杂度，初期没必要 |

## 二、详细选型分析

### 2.1 控制方案对比

```
方案A: All-in-One (不推荐)
┌─────────────────┐
│   Jetson Orin    │
│  ROS2 + 控制全部  │
│  Linux非实时 ❌   │
└─────────────────┘
   直接连电机驱动
   
方案B: 分层控制 (推荐)
┌──────────────────────────┐
│  Jetson Orin Nano         │
│  ROS2 · SLAM · 导航 · AI  │
│  (运行仿真或实物上位机)     │
└───────────┬──────────────┘
            │ USB串口 (UART)
            │ 协议: cmd_vel ↔ 车轮转速
┌───────────┴──────────────┐
│  ESP32 (底层控制器)        │
│  Arduino框架              │
│  电机PID · 编码器 · IMU    │
└──────────────────────────┘
   直接驱动电机
```

**为什么分层？**
- 仿真阶段：Jetson上跑ROS2 + Nav2，通过虚拟接口仿真
- 实物阶段：把仿真层的硬件接口换成ESP32的串口通信，上层代码不变
- 你零固件经验 → ESP32用Arduino框架可以1-2周搞定

### 2.4 仿真方案（先做这个）

```
Ubuntu 22.04 + ROS2 Humble
         ↓
安装: ros-humble-desktop + gazebo-ros-pkgs + nav2-bringup
         ↓
编写URDF: 4轮差速模型（diff_drive_plugin）
         ↓
添加传感器: LiDAR（RPLIDAR仿真）、IMU、里程计
         ↓
调通Nav2: SLAM建图 → 自主导航
         ↓
可选: YOLO检测、LLM Agent对接（都在仿真里跑）
```

**一旦仿真调通，买硬件组装后只需：**
1. 把URDF的 `hardware_interface` 从gazebo换成实物（ESP32串口）
2. 其余代码（Nav2、SLAM、视觉、AI）**一行不改**

这是"先仿真后实物"的核心价值。

## 四、避坑指南

### 固件学习常见坑

| 问题 | 现象 | 原因 | 解决 |
|------|------|------|------|
| 电机不动 | 焊好线但电机不转 | 没共地 | 驱动模块GND与ESP32 GND相连 |
| 编码器乱跳 | 数值不正常 | 中断竞争 | ESP32有PCNT外设，用PCNT替代中断 |
| PID震荡 | 电机嗡嗡响 | Kp太大 | 先纯P从0.1开始调 |
| 电池掉电 | 电机一转ESP重启 | 电压跌落 | 加1000uF电容在电源输入端 |
| IMU漂移 | 航向角飘 | 纯陀螺仪积分 | 用Mahony互补滤波 |

### 仿真常见坑

| 问题 | 解决 |
|------|------|
| Gazebo启动白屏 | 检查NVIDIA驱动，禁用nouveau |
| diff_drive_plugin找不到 | Gazebo Classic和Ignition插件名不同，确认版本 |
| Nav2规划失败 | 检查costmap参数，inflation_radius调大 |
| 仿真太慢 | 关闭不必要的传感器，降低更新频率 |

### 迁移到实物常见坑

| 问题 | 解决 |
|------|------|
| 里程计不准 | 标定轮距和轮径，用 `robot_localization` 做EKF融合 |
| 导航不稳定 | 减少max_vel_x到0.3，增加acc_lim |
| 电机响应慢 | 降低ROS2控制频率到20Hz，或优化ESP32 PID周期 |
