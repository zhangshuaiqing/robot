# 底盘选型：4轮差速 vs 履带式

> 决策参考：为通用开发平台选择底盘形式

---

## 一、核心区别

| 维度 | 4轮差速 | 履带式 |
|------|---------|--------|
| 转弯方式 | 两侧轮差速转向 | 两侧履带差速转向 |
| 地面接触 | 4个点接触（轮胎） | 面接触（履带） |
| 越障能力 | 低（≤ 轮胎半径/2） | 高（可翻越履带长度1/3障碍） |
| 室内适用性 | 优秀（不伤地面） | 一般（橡胶履带留痕、磨损木地板） |
| 室外适用性 | 硬质路面OK | 泥地、沙地、草地、碎石都OK |
| 控制难度 | 简单 | 简单（转弯逻辑几乎一样） |
| 定位精度 | 高（轮式里程计更准） | 低（履带滑移严重，里程计漂移大） |

## 二、控制难度对比

### 运动学模型

**4轮差速：**
```
左轮速度: v_L
右轮速度: v_R
线速度: v = (v_L + v_R) / 2
角速度: ω = (v_R - v_L) / d   (d = 轮距)
```

**履带差速：**
```
左侧履带速度: v_L
右侧履带速度: v_R
线速度: v = (v_L + v_R) / 2
角速度: ω = (v_R - v_L) / d - 滑移补偿项
```

**结论：控制逻辑基本一样。** 都是差速转向，代码层面的运动学模型几乎完全相同。区别在于履带需要额外处理滑移补偿，里程计精度差一些，但纯控制来说难度相当。

## 三、成本对比

| 组件 | 数量 | 单价 | 总价 |
|------|------|------|------|
| 车轮（橡胶轮，直径100mm） | 4 | 15-30 | 60-120 |
| 联轴器 | 4 | 5-10 | 20-40 |
| 底盘铝板（3mm切割） | 1 | 100-200 | 100-200 |
| 合计（不含电机） | | | **180-360** |

### 履带式

| 组件 | 数量 | 单价 | 总价 |
|------|------|------|------|

**4轮差速成本仅为履带的 40-50%。**

## 四、对你项目的影响

### 4轮差速的优势
- **成本低一半**，省下的钱可以用在更好的传感器/算力上
- **里程计精度高**：SLAM建图效果更好，定位更准（这对通用开发平台很重要）
- **结构简单**：CAD设计、加工、组装都更省事
- **室内友好**：不会伤地板，在办公室里跑没问题
- **控制代码**：ROS2 Nav2 对差速轮的支持最成熟，开箱即用

### 履带的优势
- **越障强**：可以上下台阶、过门槛、走草地
- **外观更"机器人"**：看起来更酷，展示效果加分
- **户外适应性好**：如果以后要做巡检/户外配送，履带更合适

### 但履带的硬伤
- **里程计漂移严重**：橡胶履带和地面之间不可避免的滑移，会让你的里程计短时间内快速漂移 → 影响SLAM建图和导航精度
- **磨损**：室内长时间跑，橡胶粉末会留下痕迹
- **结构复杂**：需要张紧机构、更多轴承，加工难度和故障率都更高

## 五、推荐：4轮差速

### 理由

1. **"通用开发平台"的定位**：作为开发平台，用户在意的是软件功能（SLAM、导航、视觉、AI），而不是越野能力。4轮差速的平稳性和定位精度更有利于软件调试和算法验证。
2. **成本控制**：省下的400-500元正好可以用来升级传感器或算力。
3. **控制简单，快速出成果**：Phase 1 能更快跑起来，验证整套电控系统。
4. **未来可升级**：底盘是模块化的，以后想做履带版，直接换个底盘就行，上层的电控和软件完全不变。

### 建议配置

```
┌──────────────┐
│   4轮差速底盘   │
├──────────────┤
│ 前轮 × 2     │ ← 万向轮/从动轮，仅支撑
│ 后轮 × 2     │ ← 驱动轮，无刷电机+编码器
│              │
│ 电机 × 2     │ ← 两个电机就够了，差速驱动
│              │
│ 轮距 ~250mm  │ ← 室内门宽通常700mm，预留通过性
│ 轴距 ~200mm  │
└──────────────┘
```

**为什么两驱（前万向+后驱动）而不是四驱？**
- 两驱成本更低（2个电机+2个驱动器）
- 控制更简单（不需要同步四轮速度）
- 室内硬质路面完全够用
- 四驱主要是户外越野场景需要

## 六、结论

| 你的需求 | 4轮差速 | 履带式 |
|---------|---------|--------|
| 控制难度低 | ✅ | ✅（需滑移补偿）|
| 成本低 | ✅ ~180-360 | ❌ ~430-880 |
| 开发平台定位 | ✅ SLAM/导航精度高 | ⚠️ 里程计漂移 |
| 快速出成果 | ✅ 结构简单、代码成熟 | ⚠️ 加工复杂 |
| 外观炫酷 | ⚠️ 普通 | ✅ 帅气 |
| 未来可扩展 | ✅ 换底盘即可 | — |

**建议选4轮差速两驱。** 省钱、省事、开发体验好。等以后想做户外/越野版，单独搞一个履带底盘就行了。
